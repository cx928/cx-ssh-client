cx-ssh-client 是由 程星工作室 开发的 SSH 客户端工具，支持 SSH 远程连接与 SFTP 文件管理。

⚠️ 当前版本为 预览版本（Preview），主要用于功能验证与测试。

📦 版本信息

• 当前版本：v0.0.3

• 官网：<https://www.cxbk.cc>

• 下载页面：<https://github.com/cx928/cx-ssh-client/releases/tag/cxgzs>

✨ 主要功能

• SSH 远程登录与管理

• 内置 SFTP 文件上传 / 下载 / 管理

• 轻量级设计，便于二次开发与定制

• 依赖 Python 环境，具备跨平台特性

🧰 环境依赖

• Python 3.x

• 常见依赖库（如 paramiko、cryptography 等，具体请参考项目源码）

🚀 快速开始

方式一：使用预编译包（推荐）

1. 前往 https://github.com/cx928/cx-ssh-client/releases/tag/cxgzs 下载：
   • ssh-client.v0.0.3.7z

2. 解压后，在命令行进入程序目录
3. 使用 Python 启动程序：
   python main.py
   

方式二：从源码执行

git clone https://github.com/cx928/cx-ssh-client.git
cd cx-ssh-client
python main.py
